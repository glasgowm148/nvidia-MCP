nvidia-MCP runs on your computer and connects to one explicitly configured TV through ADB and Kodi HTTP. It starts read-only. The server is free under the MIT license; your chosen AI client or model may charge separately.

Prerelease software. Live evidence is from one customized Shield. Android TV, Google TV and Android-based Fire OS are targets with hardware validation pending; Apple TV is experimental. Vega OS is unsupported. Read the evidence and platform limits.

Turn a vague problem into evidence

Inspect first

Read Kodi's version, active profile, skin, add-ons, playback state and bounded redacted logs. Check ADB and Kodi HTTP separately.

Preview a repair

Review supported configuration changes before applying them. Writes and provider browsing each require an opt-in.

Keep a way back

Supported file repairs use exact anchors, checksum checks and private backups. Disruptive tools check playback and foreground state.

How it connects

Your local MCP assistant
       ↓ stdio
nvidia-MCP on your computer
       ↓ ADB + Kodi HTTP
Your configured TV and Kodi

You need Python 3.11+, a client that supports local stdio MCP tools and access to the same home network. The agent can handle computer dependencies and configuration. You approve permissions on the TV and provide secrets privately. A browser chat alone cannot start this local process.
