Practical guide

How to use an AI assistant with Kodi on NVIDIA Shield

By glasgowm148, project maintainer · Reviewed 17 October 2026

Use a compatible assistant with local MCP support, run nvidia-MCP on your computer and authorize a connection to your TV. Then begin with read-only diagnostics.

This fits questions such as “Which Kodi profile is active?”, “Can the computer reach Kodi?” and “What errors happened around that playback failure?” It does not promise that an AI can fix any stream, recover every device or operate through an ordinary browser chat.

What you need

  • A computer and an assistant app that supports local stdio MCP tools, plus permission for it to run commands and edit its local configuration.
  • Python 3.11+ and official Android Platform Tools for the Shield/Android workflow. Your setup agent can install dependencies.
  • Your TV and computer on the same trusted home network, Kodi installed and the TV remote available.
  • The ability to approve TV debugging prompts and provide Kodi credentials through private input.

Start with the complete setup request

Copy the guided setup prompt from the README into that assistant. The agent reads the TV and computer guides, asks which device you have and walks through the matching menus. You do not need to know the TV's IP before beginning.

The setup has two different connections: ADB for supported Android-device operations, and Kodi HTTP for Kodi's own status and APIs. A connected ADB session does not prove Kodi HTTP works. Authorize the specified device rather than scanning the network.

Verify before changing anything

Ask the agent to verify the actual MCP connection, the configured TV, Kodi's version and active profile. Leave write mode and provider browsing off. A useful first request is:

Read the Kodi repair playbook and audit my configured TV read-only.
Check connectivity, Kodi version, active profile, add-ons and a bounded
redacted log excerpt. Do not navigate, stop playback, restart or change
settings. Explain the evidence and any gaps before suggesting a repair.

The server targets one explicitly configured device per instance. Secrets and recovery files stay in private local storage. Diagnostic results sent into an AI conversation are subject to your chosen client's handling, so review what you share even when the server redacts common secrets.

Add the dashboard only if you need it

Kodi Manager is an optional service inside Kodi. It supplies live supported settings, playback routing, checkpoints and reviewed home-layout editing. Its bearer token is separate from Kodi HTTP credentials and belongs to the active profile.

The complete guided prompt covers both stages. If you want only browser maintenance, you can install Kodi Manager with the TV remote without the MCP server or ADB.

Know the boundaries

nvidia-MCP is a free MIT-licensed prerelease; an assistant subscription or model usage may cost separately. Live evidence comes from one customized Shield. Google TV, Android TV and Android-based Fire OS have platform-specific setup and pending hardware validation. Vega OS is unsupported. Apple TV uses a separate experimental backend without ADB or the same offline recovery options.

Writes need an explicit opt-in. Disruptive tools also check playback and foreground state; paused media or an unknown viewing state can block them. Back up first and review a specific repair before enabling changes.
